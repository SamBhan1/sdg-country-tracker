About these numbers
  • All figures come from the UN SDG Global Database (unstats.un.org/sdgs/dataportal), downloaded with the series codes shown in Sources. Where both a country's own figure and the UN's globally comparable estimate exist for a year, the comparable estimate is used.
  • "Since 2015" compares the latest value with the first value from 2015 or later. If a country's only data is from before 2015, no change is shown.
  • "Ahead of" is the share of other countries whose latest value since 2015 is worse. For poverty, hunger, child deaths and unemployment, lower is better.
  • Countries report on different schedules, so the latest year varies by country and indicator.
