About these numbers. Data: UN SDG Global Database, United Nations Statistics Division (unstats.un.org/sdgs/dataportal), downloaded November 2026. Many values are estimates modelled by UN agencies. Countries report on different schedules, so the latest year varies.

"Since 2015" compares the latest value with the first value from 2015 or later, the year the Goals were adopted. "Ahead of" is the share of other countries whose latest value since 2015 is worse. For poverty, hunger, child deaths and unemployment, lower is better.

Independent project built on public UN data. Not an official United Nations product. Code and data: github.com/SamBhan1/sdg-country-tracker.
